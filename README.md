# Ignition · Stage Cut

An interactive, bilingual keynote on the intelligence explosion. It asks what happens when better AI speeds up the work of building the next generation of AI.

Open [index.html](index.html) in a browser. The presentation is self-contained and works offline. Use the **中文 / EN** control to switch languages.

| Key | Action |
| --- | --- |
| ← / → | Previous or next beat |
| F | Full screen |
| N | Speaker notes and current delivery cue |
| M | Toggle sound |
| O | Scene menu |
| . | Blackout |

Scene 4 lets you change how much time each research cycle saves and set a minimum cycle length. The simulation starts with a 30-day cycle and counts completed rounds over 365 days. Its assumptions illustrate how feedback affects research cadence. Select **Compare on stage** to watch the no-feedback baseline and your settings play out on the same timeline. The final scene links to the sources for the measured claims.
